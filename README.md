# 词律探微 · 清代词律声情研究助手（开源副本）

把清代（兼及宋、元）词作的**声律**做成**可复算的数字**：逐字平仄 → 句级配置 → 篇级比例 → 声情转向；
再让检索把**证据与原文**端上来，最后让大模型只负责「说得通顺」——**每一处数字都要能被引擎追认**。

> 一句口令：**数字归引擎、文料归检索、说法归生成、出处归引用。**

---

## 一、这是什么

| 组成 | 说明 |
| --- | --- |
| **确定性引擎**（`solve/`） | 逐字注音与平仄（普通话单字读音：一、二声为平，三、四声为仄；标定表纠偏多音字）、切句、篇级指标（句数／字数／平仄计数／仄声比例／前后段变化／长句阈值）、声情转向 |
| **问答链** | 自然语言提问 → 条件解析（规则路 + 可选大模型理解路）→ SQL 检索 → 证据块 → **四道护栏**（数字出处、引用逐字落地、无据认账、类型化边界声明） |
| **解题链** | 赛事题库的**甲乙两篇对比**题（C1 同调比例差／C2 分段变幅／C3 长句仄声密度／C4 后段排序／C5 景情互证） |
| **官方题型接入** | 问答链也能直接答「甲乙两篇对比」类提问（含用户自由措辞，如「曾廉《画堂春·清溪》和石孝友《画堂春》哪一首仄声比例更高？」） |
| **可选说法层** | 大模型只写叙述/论证草稿，数字仍由引擎给；未过护栏即整段回退模板 |

**三条链路共用同一份「可复算数字」**，所以网页上看到的每个数字，都能用命令行独立验一遍。

## 三、环境要求

- **Python 3.10+**（开发环境 3.11）。问答网页与检索**只用标准库**。
- 只有「**重建语料库 / 跑自检 / 跑解题链**」需要 `pypinyin`：

```bash
python -m pip install -r 项目代码/词律探微/solve/requirements.txt
```

- 不需要 GPU、不需要向量库、**默认不联网**（不启用大模型说法层时全程离线）。

## 四、五分钟上手（用仓库自带的语料库）

```bash
cd 项目代码/词律探微
python web/serve.py --port 8000          # 本机访问 127.0.0.1:8000；局域网加 --host 0.0.0.0
# Windows 上也可以直接双击「启动问答网页.bat」
```

页面：

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 问答页 | `http://127.0.0.1:8000/` | 提问、看结论+证据块+护栏结论 |
| 多条件检索 | `/browse.html` | 勾选条件组合检索 |
| 逐字解析 | `/parse.html` | 任意一篇的逐字平仄 |

命令行提问（不启网页也可以）：

```bash
python solve/ask.py --db data/corpus.db --question "清 临江仙 仄声比例高于45%"
```

**官方「甲乙两篇对比」题**（问答链会自动识别并作答）：

```bash
python solve/official.py --question "甲：清·曾廉《画堂春·清溪》（词牌“画堂春”，首句“纤尘隔断是清溪。”）。乙：宋·石孝友《画堂春》（词牌“画堂春”，首句“寒蛩切切响空帷。”）。两篇同用该调。请分别给出句数、最长句的句序和字数、全文平仄总数及全文仄声比例。"
```

## 五、从零重建语料库（可选；换语料或怀疑库坏了才需要）

## 六、跑核验（自证：每个数字都能独立复算）

| 要验什么 | 命令 |
| --- | --- |
| 自检（**235 项**程序化断言） | `python solve/selftest.py` |
| 公开集答题 + 零回归门禁（确定性 + 期望哈希 + 复算一致率 + 泛化抽样 + 引文原样性） | `python tools/regress.py --questions "…/公开测试集_700题.jsonl" --gold "…/公开测试集_700题.jsonl"` |
| 严格口径评测台 | `python solve/eval.py --pred answers_700.jsonl --gold "…/公开测试集_700题.jsonl"` |
| 解题链单题/批量 | `python solve/solver.py --question q.jsonl --corpus "../../数据/语料" --output out.jsonl` |
| 一键复现（答题→评测→不变式→自检→护栏→回归） | `python reproduce.py` |

> `tools/` 里还有逐题复核、答卷审查、双来源一致性、性能探测等门禁脚本，用法见各自的 `--help`。

## 八、隐私与密钥

- **仓库内不含任何 API 密钥、账号或个人信息**（含密钥的本地配置已替换为模板 `solve/data/llm_local.example.json`）。
- 需要大模型说法层时，任选其一：
  - 环境变量：`ZAI_API_KEY`（智谱）/ `DEEPSEEK_API_KEY` / `DASHSCOPE_API_KEY` / `UCASS_API_KEY`（校内端点）；
  - 或复制 `solve/data/llm_local.example.json` 为 `llm_local.json` 并填入自己的 key（**不要提交**）。
- 取不到密钥时自动降级为模板作答，**其余功能不受影响**。

## 十、数据出处与许可

- 清词：`snowtraces/poetry-source`（公开整理本）
- 宋词 / 元曲：`chinese-poetry/chinese-poetry`（公开整理本）
- 语料按各自仓库许可使用；本项目据公开整理本复算，**不作学术引证**。
- 数值只反映当前文本的**形式与声调配置**，不能直接推断作者意图、时代因果或作品优劣。
