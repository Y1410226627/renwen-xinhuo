## 一、30 秒上手（三种用法）

### 1. 只想看看效果（不需要装任何东西）

双击打开 `data/vue/index.html`。这是**离线自包含**页面：不联网、不需要服务器、
不需要 node_modules。左边导航可进：总览 / 逐字解析 / 多条件检索 / 知识图谱 / 校订队列。

### 2. 想用问答与在线检索（需要本地服务）

```bash
python web/serve.py            # 默认 127.0.0.1:8000，自动开浏览器
```

- 问答页：`http://127.0.0.1:8000/`
- 在线多条件检索：`http://127.0.0.1:8000/browse.html`
- 其余离线视图也可从服务访问：`/index.html` `/parse.html` `/graph.html` `/review.html`

> 接大模型（可选）：设 `ZAI_API_KEY` / `DEEPSEEK_API_KEY` / `DASHSCOPE_API_KEY` 之一。
> 不设也能用——大模型只负责「说法」，数字永远由本地引擎给。

## 二、代码在哪（改之前务必分清「真源」与「转发」）

```
frontend/src/core/*.js      ← 逻辑唯一真源（改这里才有效）
frontend/src/views/*.vue    ← 6 个视图组件
frontend/src/components/    ← AppShell 外壳
frontend/src/api.js         ← /api 客户端（含 SSE）
frontend/src/stores/theme.js← 主题

web/metrics.js 等           ← 一行 require 的「薄转发」，改这里没用
web/serve.py                ← 后端（/api + 静态路由）
web/build_views.py          ← 生成离线视图数据（不拼 HTML）
solve/                      ← 交付链（答案唯一来源，与前端物理隔离）
```

**一句话**：页面外观与交互 → 改 `frontend/src/views/`；
数字口径与渲染格式 → 改 `frontend/src/core/`；后端接口 → 改 `web/serve.py`。

## 三、改完怎么构建与自检

### 构建（顺序不能反！）

```bash
node frontend/tools/build-all.mjs      # 等价于 npm run build:all
```

它依次做三件事：
1. Vite 构建**离线视图**（5 个 HTML：首页／解析／检索／图谱／校订）→ `data/vue/`（HTML + assets）
2. Vite 构建**问答页** → `web/dist/ask/`
3. Python `web/build_views.py` 生成**数据** → `data/vue/pack.js` 等 + `data/` 门禁文件

> ⚠️ **必须「先 Vite 后 Python」**：Vite 的 `emptyOutDir` 会清空 `data/vue/`，
> 而数据文件由 Python 生成在同一目录；顺序反了数据会被清掉（页面白屏）。

### 自检（改前端就跑这一组，全绿才算改完）

| 命令 | 管什么 | 期望 |
| --- | --- | --- |
| `node frontend/tools/check-core.cjs` | 逻辑层 vs 冻结基线逐字节 | 213,972 项 0 不符 |
| `node frontend/tools/ssr-smoke.mjs` | 6 视图 SSR 渲染 | 26 项 0 不符 |

### 交付答案零回归（改前端后确认「没碰坏答案」）

```bash
python tools/regress.py --questions <公开测试集700题.jsonl> --gold <同上> --tag 公开
python tools/regress.py --questions <保密验证集300题面.jsonl> --gold <答案.jsonl> --tag 第二套
```

期望哈希：`公开 = BF863368…`、`第二套 = ACEF8B15…`（见 `solve/data/golden_sha.json`）。
**只要改的是 `frontend/` / `web/`，这两个哈希必然不变**——原因见下。

## 四、为什么改前端绝不会弄坏答案（结构性隔离）

`solve/solver.py` 只导入 `corpus` / `pronounce` / `prosody`，**不导入** `ask` / `retrieve`。
前端与 `web/` 都在交付链之外，因此**物理上不可能**影响答案哈希（见 `DECISIONS.md` D07）。

## 五、常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 门禁报 `Metrics.count is not a function` | `core/*.js` 被当 ESM，`module.exports` 失效 | 确认 `frontend/src/core/package.json` 是 `{"type":"commonjs"}` |
| 构建后页面白屏 / 五个 HTML 不见了 | 构建脚本的「清陈旧文件」判据写错，把刚构建出的 HTML 误删 | 判据必须是「上轮有、本轮无」的 **Vite 专属产物**；见 `build-all.mjs` 注释 |
| `build-all` 报退出码 1（`SAFE_DELETE_BULK_CONFIRM_REQUIRED`） | Vite 默认 `emptyOutDir` 批量删 ≥50 文件，被宿主安全删除护栏拦截 | 已设 `emptyOutDir:false` 规避；若报 `EBUSY/EPERM` 才是 `serve.py` 占句柄，先停服务 |
| 改了 `web/app_parse.js` 没效果 | 它只是薄转发 | 改 `frontend/src/core/parse.js` |
| 新增 `frontend/tools/*.js` 报 `require is not defined` | 该目录是 ESM 作用域 | CJS 脚本用 `.cjs` 后缀 |
| 沙箱里测本地服务报 502 | 走了代理 | Python `urllib` + `ProxyHandler({})` 直连 |
| `reproduce.py` 报「找不到 python」 | 子进程环境里 `spawnSync` 探测失败 | 已传 `LVC_PYTHON` 环境变量；见 `build-all.mjs` 的 `pythonExe()` |

## 六、语言构成（为什么「HTML 太多」已解决）

改造前：视图全部由 `web/build_views.py` 用**内嵌 HTML 字符串**拼出（458 行里 42 行是标签），
与逻辑、数据混在一起，接手者要先在 Python 里读懂 HTML 才能改样式。

改造后（纯代码行数，已排除文档/数据/依赖）：

| 语言 | 行数 | 占比 | 角色 |
| --- | ---: | ---: | --- |
| Python | 18,779 | 84.9% | 交付引擎 `solve/` + 口径门禁 `tools/` + 后端 `web/serve.py` |
| JavaScript | 2,127 | 9.6% | 逻辑真源 `core/` + node 门禁 + 构建脚本 |
| Vue | 863 | 3.9% | 6 个视图组件 + `AppShell` 外壳 |
| HTML | 349 | 1.6% | 仅 11 个**入口骨架**（`src/*.html`），不再内嵌模板 |
| CSS | 1 | 0.0% | 样式在 `.vue` 的 `<style scoped>` 里 |

要点：**HTML 已从「业务代码主体」降为「入口骨架」**——页面结构在 `.vue` 的 `<template>` 里
（可读、可复用、有编辑器高亮），逻辑在 `.js` 里，数据由 Python 生成后以 `window.__PACK__` 注入。
三者各归其位，接手者不必再读 Python 里的 HTML 字符串。

## 八、研究库（页面导航里的「研究库」；2026-10-09 新增）

**一句话**：问答页回答「这一问问什么」；研究库管「研究过程中攒下来的东西」——
摘录、事实、读音裁定、词谱对照、自己的录入、批量导入、历史快照，都在这一页。

**打开方式**：先启动本地服务（`python web/serve.py`），浏览器打开
`http://127.0.0.1:8000/research.html`（或从任意页顶部导航点「研究库」）。
⚠ 从文件夹双击打开的离线副本里，这一页**只能看说明**——它的功能需要本地服务（要写库）。

**七个分区怎么用**

| 分区 | 干什么 | 记住一条 |
| --- | --- | --- |
| 文献摘录 | 录入书里的材料；「编辑」=追加新版本，旧版本永远在 | 删除=撤回标记，行不会消失 |
| 研究事实 | 登记「陈述 + 出处」；给作品句或材料定位二选一 | 引文会自动与原文**逐字核对**，对不上拒绝入库 |
| 读音裁定 | 某篇某句某字选一个读音（多来源候选点选） | 选定/撤回都写「决策事件」，可完整回溯；解析页与问答证据会按裁定修正展示 |
| 词谱对照 | 作品原字 / 规范 / 谱书例词 三行对照 | 数据来源已注明「搜韵公开转写（**未核原书**）」——研究参考，不是原书核验 |
| 我的录入 | 录入自己的作品（草稿→材料样例→已对上来源） | 「已对上来源」必须写明来源，不许空口自证 |
| 批量导入 | 传 JSONL 文件批量录入；批次可对账、可回滚 | 重复导入不会产生重复行（幂等） |
| 历史快照 | 每轮问答自动冻结一份；可回查 | 回查看到的是**当时**的内容，绝不重算；口径变了会标「依赖已陈旧」 |

**命令行等价**（批量导入，适合大文件）：

```bash
python tools/import_batch.py --file 我的录入.jsonl --tag 第一批      # 导入
python tools/import_batch.py --file 我的录入.jsonl --tag 试算 --dry-run  # 只体检不写库
python tools/import_batch.py --list                                  # 批次对账
python tools/import_batch.py --rollback 3 --why 录错了                # 回滚批次
```

**数据存在哪**：研究库在 `data/research.db`（独立小库）；问答快照在 `data/snapshots/`。
两者都**不随开源仓分发**（属于你自己的本地研究数据），也**永远不会碰**只读语料库 `data/corpus.db`。
