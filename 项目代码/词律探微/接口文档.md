# 词律探微 · 接口文档（`web/serve.py`）

> 服务只依赖 Python 标准库，默认端口 8000（被占用自动顺延，启动日志会打印实际端口）。
> 返回体统一为 JSON（`/api/ask_stream` 为 SSE 流）。
>
> ⚠ **2026-10-09 修订（架构级变化，见 `DECISIONS.md` D32）**：本项目接口原来**全部为只读 GET**；
> 自研究库批次起新增**写接口（POST）**——只服务**已登记的研究库路径**（文献摘录 / 研究事实 /
> 读音裁定 / 个人录入 / 批量导入 / 版本链），写操作带**幂等键**（`client_token`）。
> **`data/corpus.db`（58,852 篇语料）仍然只读打开**；写接口只写独立的研究库 `data/research.db`。
> 服务默认绑定 `127.0.0.1`（本地单机）；以 `--host 0.0.0.0` 局域网部署时须知写接口一并暴露。

## 0. 通用约定

| 项 | 说明 |
| --- | --- |
| 基址 | `http://<host>:<port>`（局域网部署见 `部署文档.md`） |
| 编码 | UTF-8；`Content-Type: application/json; charset=utf-8` |
| 错误 | HTTP 400 `{"error":{"code":"...","message":"..."}}`；500 只回 `request_id`，细节进服务端日志（`LVC_DEBUG=1` 可回吐） |
| 取消 | 客户端断开即取消对应的模型调用（`request_id` + 取消事件 + 有界队列） |

## 1. 接口一览

| 接口 | 方法 | 作用 |
| --- | --- | --- |
| `/api/ask` | GET | **问答主接口**：问句 → 条件 → 检索 → 证据块 → 护栏结论 |
| `/api/ask_stream` | GET | 同 `/api/ask`，以 **SSE** 流式返回（`understanding`→`final`，或 `error`） |
| `/api/search` | GET | 多条件结构化检索（表单同款条件），返回篇数与篇目 |
| `/api/nl2query` | GET | 把问句解析成**结构化条件**（可人工修改后再检索） |
| `/api/summarize` | GET | 把检索结果写成一段话（数字仍由引擎给，须过四道护栏） |
| `/api/compare` | GET | 分组对比（如按朝代比仄声比例），两种口径同时给出 |
| `/api/catalog` | GET | 语料总览统计（总篇/句/词人/词牌、朝代·来源·声情分布、榜单）；**全部 SQL 现算** |
| `/api/identify` | GET | 实体身份判定：`exact`／`ambiguous`／`unavailable` 三态 + 近似候选 |
| `/api/cipu/list` | GET | 词谱库覆盖的词牌一览（功能 9；返回体带来源声明） |
| `/api/cipu` | GET | 某词牌的全部体式（逐句规则 + 谱书例词） |
| `/api/cipu/compare` | GET | **词谱三行对照**（作品原字 / 规范 / 谱书例词；带 `source_note` 红线声明） |
| `/api/intake` | GET | **录入体检**（功能 11，只读）：必填/题名当正文/句读/词牌体式匹配 |
| `/api/materials`、`/api/material` | GET | 文献摘录列表 / 单条版本链（功能 6） |
| `/api/facts` | GET | 研究事实列表（功能 7；可按 `poem_pid`/`material_id` 过滤） |
| `/api/text_versions`、`/api/meta_revisions` | GET | 文本版本链 / 元数据修订史（功能 15） |
| `/api/works` | GET | 个人录入列表（功能 12；`state` 三态过滤） |
| `/api/pronounce/candidates`、`/api/pronounce/decisions` | GET | 读音候选（多来源）/ 决策全史（功能 8） |
| `/api/import/batches` | GET | 批量导入批次对账（功能 13） |
| `/api/snapshots`、`/api/snapshots/<id>` | GET | 问答快照列表 / **回查**（功能 1；原文返回 + 陈旧标注） |
| `/api/research/summary`、`/api/research/decisions` | GET | 研究库概况 / 决策事件审计 |
| `/api/parse` | GET | 逐字平仄/四声/韵脚（按 `pid`；有读音裁定时按裁定修正展示，附 `pron_adjusted`） |
| `/api/rand` | GET | 随机取一篇（可按 `dyn`） |
| `/api/examples` | GET | 示例问句 |
| `/api/llm` | GET | 大模型可用性与模型名 |
| **写接口（POST）** | 见 §6 | 研究库写操作（幂等键 + JSON 请求体） |
| `/`、`/browse.html`、`/parse.html`、`/graph.html`、`/review.html`、`/research.html` | GET | 网页与视图 |

## 2. `/api/ask`（核心）

**参数**

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `q` | — | 问句（必填） |
| `topk` | 3 | 返回篇数，夹在 1–200 |
| `parse` | 0 | 附逐句解析 |
| `narrate` | 0 | 用大模型写说明（数字仍由引擎给） |
| `argument` | 0 | 论证辅助草稿 |
| `ctx` | — | 服务端会话号（`sid`），用于多轮 |
| `ctx_pids` | — | 直接指定「上一轮结果集」（不带会话时用） |
| `carry` | 0 | 显式「承上一轮」开关 |

**返回体要点**

| 字段 | 说明 |
| --- | --- |
| `answer` | 结论正文 |
| `spec` | 本轮**理解结果**（人类可读） |
| `blocks[]` | 证据块 `[E#]`：篇目元信息、逐句原文、相关指标 |
| `total` | 命中篇数（聚合/极值题为对应数值） |
| `verify` | 护栏结论 `{ok, 问题列表}`（数字出处／引用逐字／无据认账／类型化边界） |
| `refused` / `reason` | 是否拒答及**结构化理由**（ok/partial/not_found/unavailable/unsupported/ambiguous…） |
| `set_check` | **集合身份校验**：`status` ∈ `VERIFIED_EXACT｜VERIFIED_DERIVED｜SEMANTIC_NOT_EXHAUSTIVE｜NOT_CHECKED｜FAILED`，另含 `agg_status`(PASS/FAIL/NOT_EXECUTED)、`extra/missing`、`truncated` |
| `plan` / `provenance` / `provenance_text` | `LVC_PLANNER=plan` 时附**查询计划**与**溯源 DAG**（人话版可在界面展示） |
| `safety` | 内容安全结果 |

> **「未验证 ≠ 已验证」**：语义类问题不存在可判定的完整命中集，`set_check.status` 会明确写
> `SEMANTIC_NOT_EXHAUSTIVE`，前端**不得**把它显示成 ✓。

## 3. `/api/search` 参数（与前端表单一一对应）

`q, author, cipai, tail, tailPz, pz, minZe, maxZe, minLen, maxLen, minSent, maxSent, scene, order, page, size`
（多值条件支持 OR；`author/cipai` 支持 `contains/exact/prefix`）

## 3.1 `/api/catalog`（语料总览统计）

**参数**：`top`（榜单条数，1–100，默认 20）。

**返回体**：

| 字段 | 说明 |
| --- | --- |
| `totals` | `{poems, lines, authors, cipai}` —— 四张表的真实行数 |
| `dynasty` / `source` / `scene` | `[{name, poems}]`：朝代、语料来源、声情转向的分布 |
| `ze_ratio_buckets` | 仄声比例分桶计数；标签与 `RATIO_BUCKETS`、前端分面**同一口径**（半开区间） |
| `top_authors` / `top_cipai` | 作数榜（按篇数降序、同数按名升序） |
| `meta` | 建库时写入的元信息（含标定表指纹 `overrides_sha`） |

> **口径**：所有数字都用**本库 SQL 现算**，不读任何预生成缓存——避免「构建产物过期导致网页数字与库不一致」。

## 3.2 `/api/identify`（实体身份判定）

**参数**：`kind` ∈ `cipai`（默认）｜`author`｜`title`；`text` 为待判定名称。

**返回体**：`status` 三态 + `matches` 候选 + `note` 人话说明。

| `status` | 含义 | 调用方应做什么 |
| --- | --- | --- |
| `exact` | 库里正好有同名实体（`exact.n` 为篇数） | 直接按此名检索 |
| `ambiguous` | 无同名但有**包含关系**的近名 | **必须让用户确指**，不许自动挑一个 |
| `unavailable` | 无同名也无包含关系（`matches` 为 difflib 近似，**仅供提示**） | 如实告知「库里查无此名」 |

> 前端用法：检索命中为 0 且填了词牌/词人时自动问一次，把候选做成可点 chip（`ParseView.vue`）。
> 判定的实现是 `solve/entity_resolve.identify()`，与 `resolve()`（从整句里捞前缀实体）**职责不同**。

## 3.3 研究类接口（2026-10-09 新增；对应功能 1/6/7/8/9/11/12/13/15）

- `/api/cipu/compare?pid=&tune=&form=` —— 词谱三行对照。返回 `rows[]`（每句：作品原字 `cells`、
  规范 `rule_tones`、句尾标记 `ending`、谱书例词 `example`）与 `summary`（合/不合/平仄皆可三分账）。
  **`source_note` 为红线字段**：「参照来源：搜韵公开转写（未核原书）· 上游 hulbji/couyun（MIT）」；
  词牌未收录 / 有歧义时 `status='no_tune'` 并如实给出候选与可用词牌清单。
- `/api/intake?title=&cipai=&content=` —— 录入体检（**只读**）。返回 `ok / issues[]（error|warn|info）
  / stats / tune_check`；与「题名当正文」历史 bug 同口径，**不误伤**正文中的常见词。
- `/api/snapshots`、`/api/snapshots/<id>` —— 问答快照列表与**回查**。回查**原文返回、绝不重算**；
  口径（语料/标定表/答案基线）变化时附 `stale=true`、`stale_fields`、`stale_note`
  （「依赖已陈旧…旧答案原样保留、未经重算」）。
- `/api/pronounce/candidates?pid=&line=&pos=` —— 读音候选（pypinyin 异读 ∪ 字级标定表）+ 语料基线 +
  当前裁定 + 该字位**决策史**（含撤回）。`pos` = 该句第几个**汉字**（0 起，与 `pz` 串同口径）。
- `/api/materials` / `/api/material?material_id=` / `/api/facts` / `/api/text_versions?pid=` /
  `/api/meta_revisions?pid=` / `/api/works?state=` / `/api/import/batches` —— 见 §1 一览。

## 3.4 写接口（POST；2026-10-09 首次引入——架构级变化，见 `DECISIONS.md` D32）

**通用约定**

| 项 | 说明 |
| --- | --- |
| 请求体 | JSON 对象，`Content-Type: application/json`，上限 **1 MB**（超限 413） |
| 成功 | `200 {"ok": true, "result": {…}}` |
| 失败 | `400 BAD_PARAM`（参数校验）/ `404 NOT_FOUND_WRITE`（未登记路径）/ `413` / `500 INTERNAL` |
| **幂等** | 所有写接口接受 `client_token`（≤128 字符）。**同一 token 重复提交返回第一次的结果**，不重复执行；不传则不启用幂等（正常执行一次） |
| 并发 | 服务端以 `BEGIN IMMEDIATE` 事务 + 进程内锁串行化写操作；两个并发同 token 请求也只会落一行 |

| 路径 | 作用 | 关键参数 |
| --- | --- | --- |
| `POST /api/text_versions` | 追加文本版本（功能 15） | `pid`、`content`；可选 `scope/version_type/parent_id/note` |
| `POST /api/meta_revisions` | 追加元数据修订（功能 15） | `pid`、`field`、`new_value`；可选 `old_value/basis/why` |
| `POST /api/materials` | 新建文献摘录（功能 6） | `title`、`content`；可选 `author/year/locator/…` |
| `POST /api/material_revisions` | 追加摘录新版本（不改旧版） | `material_id`、`content` |
| `POST /api/materials/withdraw` | 撤回材料（标记 + 决策事件） | `material_id`、`why` |
| `POST /api/facts` | 登记研究事实（功能 7） | `statement` +（`poem_pid`〔+`line_idx`/`span_*`/`evidence`〕 或 `material_id`）；**无出处拒收** |
| `POST /api/facts/withdraw` | 撤回事实 | `fact_id`、`why` |
| `POST /api/pronounce/decide` | 读音裁定（功能 8） | `pid/line/pos/reading/tone`（reading 末位声调须与 tone 一致）；可选 `basis/why` |
| `POST /api/pronounce/withdraw` | 撤回裁定（回基线） | `decision_id`、`why` |
| `POST /api/works` | 录入个人作品（功能 12） | `title/content`；`verification_state` 默认 `draft`（选 `source_matched` 必填 `source`） |
| `POST /api/works/verify` | 作品核验状态流转 | `work_id`、`state`、`source`（流转到 `source_matched` 必填） |
| `POST /api/import` | 批量导入（功能 13） | `tag`、`files:[{name, rows:[…]}]`；同内容重复导入返回既有批次 |
| `POST /api/import/rollback` | 回滚批次 | `batch_id`、`why` |

> **红线**：写接口只写 `data/research.db`（研究库），**绝不写** `data/corpus.db`。
> 全部写操作留**决策事件**（`/api/research/decisions` 可审计：谁/何时/选了什么/依据/为什么）。

```bash
python solve/plan_exec.py --question "…"                          # 计划 + 逐步执行 + 溯源
```
