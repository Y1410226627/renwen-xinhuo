# 词律探微 · 接口文档（`web/serve.py`）

> 服务只依赖 Python 标准库，默认端口 8000（被占用自动顺延，启动日志会打印实际端口）。
> 对外接口**全部为只读 GET**；不接收上传、无写库接口、语料库只读打开。
> 返回体统一为 JSON（`/api/ask_stream` 为 SSE 流）。

## 0. 通用约定

| 项 | 说明 |
| --- | --- |
| 基址 | `http://<host>:<port>`（局域网部署见 `部署文档.md`） |
| 编码 | UTF-8；`Content-Type: application/json; charset=utf-8` |
| 错误 | HTTP 400 `{"error":{"code":"...","message":"..."}}`；500 只回 `request_id`，细节进服务端日志（`LVC_DEBUG=1` 可回吐） |
| 取消 | 客户端断开即取消对应的模型调用（`request_id` + 取消事件 + 有界队列） |

## 1. 接口一览

| 接口 | 方法 | 作用 |
| --- | --- | --- |
| `/api/ask` | GET | **问答主接口**：问句 → 条件 → 检索 → 证据块 → 护栏结论 |
| `/api/ask_stream` | GET | 同 `/api/ask`，以 **SSE** 流式返回（`understanding`→`final`，或 `error`） |
| `/api/search` | GET | 多条件结构化检索（表单同款条件），返回篇数与篇目 |
| `/api/nl2query` | GET | 把问句解析成**结构化条件**（可人工修改后再检索） |
| `/api/summarize` | GET | 把检索结果写成一段话（数字仍由引擎给，须过四道护栏） |
| `/api/compare` | GET | 分组对比（如按朝代比仄声比例），两种口径同时给出 |
| `/api/parse` | GET | 逐字平仄/四声/韵脚（按 `pid`） |
| `/api/rand` | GET | 随机取一篇（可按 `dyn`） |
| `/api/examples` | GET | 示例问句 |
| `/api/llm` | GET | 大模型可用性与模型名 |
| `/`、`/browse.html`、`/parse.html`、`/graph.html`、`/review.html` | GET | 网页与离线视图 |

## 2. `/api/ask`（核心）

**参数**

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `q` | — | 问句（必填） |
| `topk` | 3 | 返回篇数，夹在 1–200 |
| `parse` | 0 | 附逐句解析 |
| `narrate` | 0 | 用大模型写说明（数字仍由引擎给） |
| `argument` | 0 | 论证辅助草稿 |
| `ctx` | — | 服务端会话号（`sid`），用于多轮 |
| `ctx_pids` | — | 直接指定「上一轮结果集」（不带会话时用） |
| `carry` | 0 | 显式「承上一轮」开关 |

**返回体要点**

| 字段 | 说明 |
| --- | --- |
| `answer` | 结论正文 |
| `spec` | 本轮**理解结果**（人类可读） |
| `blocks[]` | 证据块 `[E#]`：篇目元信息、逐句原文、相关指标 |
| `total` | 命中篇数（聚合/极值题为对应数值） |
| `verify` | 护栏结论 `{ok, 问题列表}`（数字出处／引用逐字／无据认账／类型化边界） |
| `refused` / `reason` | 是否拒答及**结构化理由**（ok/partial/not_found/unavailable/unsupported/ambiguous…） |
| `set_check` | **集合身份校验**：`status` ∈ `VERIFIED_EXACT｜VERIFIED_DERIVED｜SEMANTIC_NOT_EXHAUSTIVE｜NOT_CHECKED｜FAILED`，另含 `agg_status`(PASS/FAIL/NOT_EXECUTED)、`extra/missing`、`truncated` |
| `plan` / `provenance` / `provenance_text` | `LVC_PLANNER=plan` 时附**查询计划**与**溯源 DAG**（人话版可在界面展示） |
| `safety` | 内容安全结果 |

> **「未验证 ≠ 已验证」**：语义类问题不存在可判定的完整命中集，`set_check.status` 会明确写
> `SEMANTIC_NOT_EXHAUSTIVE`，前端**不得**把它显示成 ✓。

## 3. `/api/search` 参数（与前端表单一一对应）

`q, author, cipai, tail, tailPz, pz, minZe, maxZe, minLen, maxLen, minSent, maxSent, scene, order, page, size`
（多值条件支持 OR；`author/cipai` 支持 `contains/exact/prefix`）

## 4. 命令行等价入口

```bash
python solve/ask.py --db data/corpus.db --question "清 临江仙 仄声比例高于45%"
python solve/queryplan.py --question "清 临江仙 仄声比例高于45%"   # 只看「理解成什么计划」
python solve/plan_exec.py --question "…"                          # 计划 + 逐步执行 + 溯源
```
