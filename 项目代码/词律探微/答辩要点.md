# 答辩要点（决赛路演用）

> 决赛评分：技术创新 15 ／ 场景价值与创新性 15 ／ 师生交互体验 10 ／ 完成度与稳定性 15 ／ 现场路演 25 ／ 答辩表现 20

## 一、10 分钟演示脚本（建议）

| 时间 | 演示 | 命令/页面 |
| --- | --- | --- |
| 0–1′ | 一句话定位：把清词声律做成**可复算的数字** | README「一句口令」 |
| 1–3′ | 声律自动解析：任选一篇看逐字平仄/句脚/声情 | `/parse.html` |
| 3–5′ | 声情智能问答：问一句，看**结论 + 证据块 + 护栏结论** | `/` 问答页 |
| 5–6′ | 开放措辞：同义改写三种问法 → 同一集合 | `tools/nl_benchmark.py` |
| 6–8′ | 复杂组合：跨值 OR / 否定 / 计数 → **查询计划 + 溯源 DAG** | `solve/plan_exec.py` |

## 二、加分点（评委最容易记住的三件事）

1. **证据与身份双验证**：不只是"数字有出处"，还会用**独立 SQL 复算**比对返回的**篇号集合**，
   直接把"答对数字、答错集合"这类静默错答暴露出来（`answer_verify.py` 五态）。
2. **未验证就如实说未验证**：语义类问题标 `SEMANTIC_NOT_EXHAUSTIVE`，绝不显示成 ✓。
3. **无效实体不退化成全库**："查无此人/此调"编译为恒假哨兵 → 结果集为空，
   而不是"删掉条件查全库"（`planner._mark_not_found`，附自检）。

## 三、预判问答

| 问 | 答 |
| --- | --- |
| 和"直接让大模型回答"有什么本质区别？ | 大模型不产生数字与事实；数字全部由确定性引擎给出，且可被独立复算。大模型只做"规划"与"成文"。 |
| 为什么还要做向量检索？ | 只有"写秋景""主题相近"这类**词面不重合**的语义问法才用向量；且向量只作**候选生成**，最终判定仍走确定性条件。 |
| 幻觉怎么防？ | 四道护栏（数字出处/引用逐字/无据认账/类型化边界）+ 集合身份校验 + 说法层不过护栏即整段回退模板。 |
| 数据从哪来？合规吗？ | 公开整理语料（poetry-source、chinese-poetry），不含个人信息与涉密内容；不使用境外模型/智能体工具。 |
| 模型换了会怎样？ | 嵌入索引有 manifest 强校验（指纹/模型/版本/维度/条数），换模型或换语料即判索引失效并提示重建；大模型只影响"规划/成文"，不影响数字。 |
| 为什么默认不用规划路？ | 零回归生命线：公开 700 题逐字节哈希不得变。规划路以 `LVC_PLANNER=plan` 启用，实测开放措辞 20/40 → 28/40；下一步按 Phase 4 仲裁再考虑改默认。 |
| 能处理"数据库里没有"的问题吗？ | 会明确说明"语料未见支持"或"0 是确切结果"，不拿相近篇目凑数。 |

## 四、演示现场兜底

- 大模型网关不通 → 勾选项自动失效，**确定性问答与五视图完全不受影响**；演示脚本第 6 步可改用
  `python solve/queryplan.py --question "清朝或宋朝的临江仙有哪些"` 展示计划（无需模型）。
- 向量索引未建 → 语义问法自动降级并如实说明原因（`vector_index.why()`）；其余功能不受影响。
