## 一、本遍新发现并已修复（1 处中问题）

### P7-1【中】`views/CipuView.vue` 的 `isHttpUrl()` 与 `ResearchView.vue` 口径不一致（H4 同类）

- **位置**：`frontend/src/views/CipuView.vue:201`（改前）
- **现象**：第 1 遍已把 `ResearchView.vue` 的 `isHttpUrl` 收紧为「**只看显式 http(s):// 前缀**」，
  但 `CipuView.vue` 里**另有一份同名函数**，仍是旧的 `new URL(u, window.location.href)` + 协议判等写法。
  带 base 解析会把 `//evil.com`（协议相对）、`foo/bar`（相对路径）都解析成**本站 http(s) 协议**
  → 判为「可用链接」，比后端 `safe_url`（必须显式前缀）**更宽**。
- **影响面**：`t.source_url` 用于谱库来源链接（`:35`）。写入侧/出库侧已拦，这里是**第三道闸**，
  与 ResearchView 的修法不一致 = 双标（同一个安全承诺，两页两种实现）。
- **修法**：改为与 ResearchView **逐字一致**的写法：

  ```js
  function isHttpUrl(u) {
    if (!u) { return false; }
    return /^https?:\/\//i.test(String(u).trim());
  }
  ```

  并在注释里写明「自查第 7 遍修」及与后端 `safe_url` 的对齐理由。
- **复验**：重建产物后 `test_ui` 147/0、`ssr-smoke` 31/0、`test_cipu` 54/0 全绿。

## 二、本遍新发现并已修复（1 处中问题·暗色可读性）

### P7-2【中】`views/GraphView.vue` 图谱标签深色硬编码，暗色主题下近乎不可读

- **位置**：`frontend/src/views/GraphView.vue`（layout 计算属性 + 模板 + 样式）
- **现象**：节点**标签文字**颜色写死为 `#1b4f80`（深蓝，词人）/ `#8a4a10`（深棕，词牌），
  边描边 `#5b86b8`、计数 `#7a8b9a` 亦写死；而核心样式 `.chart .nd text` 带
  `stroke: var(--panel)` 光晕——在 `prefers-color-scheme:dark`（或 `data-theme=dark`）下
  **深字 + 深色光晕 + 深底**，对比度约 **1.9:1**，标签基本看不清。
  注释却宣称「配色沿用 core/ui.js 变量」，与事实不符（同「注释说谎」一类）。
- **约束**：`web/test_ui.js:215-216` **断言**产物含 `#1f6fb2`（词人圆点）/ `#c2691a`（词牌圆点）
  → **圆点填充是门禁契约，不能动**（保留模板内联 `:fill` 与图例色块）。
- **修法**：只改**文字色与连线色**，令其走核心主题变量（天然亮/暗双套，无需写两段媒体查询）：
  - `tfill` 内联色 → 改输出 `tclass`（`t-author` / `t-cipai`）；
  - 样式：`.nd text.t-author{fill:var(--ping)}`、`.nd text.t-cipai{fill:var(--accent2)}`、
    `.nd text .t-cnt{fill:var(--ink2)}`、`.chart .ed{stroke:color-mix(in srgb,var(--ping) 55%,transparent)}`；
  - SVG 顶部两行说明文字（原 `fill:#6b7a88`）改 `class="gv-title"/"gv-sub"` →
    `fill:var(--ink)/var(--ink2)`。
  - `--ping` 亮 `#2f5d7c` / 暗 `#8fb6d4`（本就是「词人蓝」），`--accent2` 亮 `#8a6a53` / 暗 `#c9ab8c`
    （「词牌棕」），语义一一对应。
- **复验**：重建产物，`grep` 确认 `#1f6fb2`/`#c2691a` **仍在**（门禁不破）且新增 `t-author`/`t-cipai` 类名；
  `test_ui` 147/0、`test_render` 522242/0、`ssr-smoke` 31/0、`check-types` 0 错全绿。
