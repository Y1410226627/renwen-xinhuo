## 二、`ui.js`：CSV 公式注入 + revoke

- `csvCell`（`:239-243`）：`/^[=+@]/` 或 `/^[\t\r]/` 或 `/^-[^0-9.]/` 前置单引号。
  - `-3.5` → 匹配 `^-[0-9.]` **不**加引号 → 保持数值列可计算。✔（符合"例外"设计）
  - `-DRAFT` / `=cmd|…` / `+1` / `@SUM` / 首字符 TAB/CR → 加引号。✔
  - 单独的 `-`：不匹配任一规则，不加引号——Excel 不会把裸 `-` 当公式，无风险。✔
- `_save`（`:257-269`）：`revokeObjectURL` 放在 `setTimeout(…, 0)`（下一轮事件循环）——
  **不是立即释放**，避免部分浏览器取消下载；同时摘除临时 `<a>` 节点。✔
- `download` / `downloadJson` 都改走 `_save`；JSON **不带 BOM**、CSV **带 BOM** 的差异保留。✔
