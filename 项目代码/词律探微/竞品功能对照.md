## 二、竞品没有、我们更要有（本项目独有）

1. **全量语料 + 确定性引擎**：58,852 篇（清/宋/元）预计算平仄、句脚、声情；数字可独立复算（双集哈希逐字节不变）。
2. **规划式问答**（Planner→Plan→Executor）：多步、布尔嵌套、语义召回、结果溯源 DAG。
3. **路线透明**：每次回答报告实际走的链、召回执行情况、失败原因（`route`）。
4. **结果状态六态**：确切空／未召回到／未听懂／语义候选（非穷尽）／精确／拒答。
5. **字段×算子真值测试**（`op_truth_check` 36 项）、**文学解释基准**（8 条，含召回相关性锚点）。
6. **四道护栏**：数字有出处、引文逐字落地、边界声明、拒答不编造。
7. **快照留痕 / 幂等写 / 决策事件**：所有人工动作可回溯、可撤回。

  三 pill 开关承载，见 D44）；
- 前端（D44）：**问答 UI 对话化**——左栏会话（今天/昨天/更早分组）+ 用户右对齐气泡 +
  「已执行（用时 N ms）」折叠 + 复制/重新生成/朗读/导出操作行 + 粘性 composer
  （自适应高度、Enter 发送、pill 开关、圆形发送钮）。

- ~~我们没有韵书数据库~~ → **2026-10-10 已引入《广韵》**（推音 tshet-uinh，MIT · Project NK2028，
