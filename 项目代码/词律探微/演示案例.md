# 词律探微 · 演示案例（答辩/评审用）

> 五个演示各配一条**命令行可复现**的入口；网页端对应操作在括号里。
> 所有数字都可由引擎独立复算，见 `复现报告.md` 与 `README.md` 第六节的核验命令。

## 案例 1 · 声律自动解析（功能①）

```bash
python solve/prosody.py --db data/corpus.db --pid "ci.清.0001.base.json#723"
```
输出该篇**逐字平仄/四声**、句数、最长句、平仄计数、仄声比例、前后段变化与声情转向。
（网页：`/parse.html` 选篇即看）

## 案例 2 · 声情智能问答（功能②）

```bash
python solve/ask.py --db data/corpus.db --question "清 临江仙 仄声比例高于45%"
```
返回**结论 + 证据块 [E#] + 四道护栏结论**。（网页：首页问答框）

**开放措辞对照**（同一问题换三种说法，应得同一集合）：
`清代临江仙里仄声比例高于45%的有哪些` / `清词中的临江仙，仄声占比超过45个百分点` / `临江仙这调，清朝人写的，仄声比例在45%以上`

## 案例 3 · 复杂组合与多步（工具丰富度）

```bash
python solve/plan_exec.py --question "清朝或宋朝的临江仙有哪些"      # 跨值 OR
python solve/plan_exec.py --question "不属于临江仙的清词有多少"        # NOT
python solve/plan_exec.py --question "清词里临江仙的数量是多少"        # 计数
```
开启规划路（`set LVC_PLANNER=plan`）后，这三类问题由 Planner 产出**布尔树/多步计划**并由执行器逐步执行，附 `provenance_text` 溯源链。

## 案例 4 · 论证辅助生成（功能③）

```bash
python solve/ask.py --db data/corpus.db --question "清 临江仙 仄声比例高于45%" --narrate 1
```
大模型只写叙述；**任一数字或引文过不了护栏就整段回退模板**——宁可话糙不可错。

## 案例 5 · 校订建议队列（功能④）

```bash
python tools/review_diff.py --corpus "../../数据/语料" --out data/reviews.csv
```
产出工单（依据/状态/建议），网页 `/review.html` 可筛选、排序、导出。
（接受/驳回/写回的内核在 `tools/review_apply.py`；Web 端写接口为赛前未接项，见 `外部审查处置表.md` #59）

## 案例 6 · 知识图谱导航（功能⑤）

浏览器打开 `data/vue/graph.html`（无需起服务）：清代**词人 ↔ 词牌**二部图，可筛选、悬停高亮、截图。

## 案例 7 · 证据与身份校验（评审加分点）

```bash
python solve/answer_verify.py     # 集合身份五态 + 聚合复算三态
python tools/nl_benchmark.py      # 开放措辞基准（独立 SQL 真值，非自证循环）
```
说明：`set_check.status` 会把「已用独立 SQL 逐篇复算」「语义排序、无完整命中集」「未校验」**分开报**，
杜绝「答对数字、答错集合」的静默错答。

## 案例 8 · 一键复现（可复现性）

```bash
python reproduce.py --skip-build --quick
```
生成 `复现报告.md`：每一步的**实际输出**（非预期值）都写进报告，任何人可重跑验伪。
